# SKILLS — reusable procedures

- **Phase exit:** see `ROUTINES.md`.
- **Add a service:** create the package, wire it into the workspace, set its coverage threshold, add a Helm chart,
  runbook and threat-model entry, and update the status table in `CLAUDE.md`.
- **Change a frozen contract:** write an ADR first, then update the contract, contract tests, and SDKs.
