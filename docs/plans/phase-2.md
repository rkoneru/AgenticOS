# Phase 2 plan — Governed kernel (the core loop)

Goal: one ABL agent runs end to end through the fail-closed gate; allowed/denied correctly; run replays from the log.

## Components and owners (parallel after the Phase 1 freeze)

## Shared interfaces (fixed here so work can proceed in parallel)

### Gate request context (policy input)

`input` for Rego / `EvaluateRequest.context`: `tool.{name,kind,side_effects}`, `args.*`, `data.phi`, `tenant.id`,
`agent.{name,version}`, `run.id`, `actor.{type,id}`, `enforcement_point`. Policy DSL `field` paths address this document.

### RuntimeManifest v1 (output of A, input of E)

```json
{
  "manifest_version": 1,
  "blueprint": { "name": "", "version": "", "content_hash": "<sha256 of canonical ABL JSON>" },
  "risk": { "level": "minimal|limited|high", "human_oversight_required": false, "approver_roles": [], "transparency_notice": null },
  "models": { "primary": { "provider": "", "model": "", "endpoint": null, "params": {} }, "fallbacks": [] },
  "routing": { "stages": ["llm"] },
  "system_prompt": "",
  "tools": [{ "name": "", "kind": "function|mcp|code|browser|channel|agent", "ref": null, "mcp_server": null, "side_effects": "none|read|write|external", "timeout_seconds": 60 }],
  "memory": { "run": true, "session": false, "long_term": false, "knowledge_bases": [] },
  "budgets": { "tokens": {"soft": null, "hard": null}, "cost_usd": {...}, "runtime_seconds": {...}, "tool_calls": {...} },
  "process": { "restart_policy": "never", "max_restarts": 0, "max_children": 0, "timeout_seconds": null, "supervisor": "one-for-one" },
  "policy_packs": [], "channels": [], "data": { "phi": false, "residency": null }, "evals": []
}
```

Defaults are applied by the compiler (`side_effects` defaults to `write`, `routing.stages` to `["llm"]`, `memory.run` to true).
Compilation is pure and deterministic. Lint findings have `severity: error|warning`, a stable `code`, and a JSON path.

### Audit sink (TS, `@axis/contracts`)

`AuditSink.append(event: UnsealedEvent): Promise<AuditEvent>` assigns `seq/prev_hash/hash` (per-tenant chain) and is the only way
the Risk Kernel writes audit. Every gate decision, including DENY and errors, is appended **before** the decision is returned
(if the append fails, the decision is DENY).

### Gate wire contract

`proto/axis/runtime/v1/gate.proto` `GateService.Evaluate`. Client rule: transport error, deadline, or `DECISION_UNSPECIFIED` = DENY.
Python runtime gets stubs generated from `/proto` (do not hand-edit generated code).

## Branch/merge protocol

Agents work in git worktrees on local branches `p2/<component>` and commit there; they do **not** push. The orchestrator merges.
Each agent owns only its own directories; shared files (`pnpm-lock.yaml`, `uv.lock`, root configs) are regenerated by the
orchestrator after merge. Frozen files (`FREEZE.json` paths) must not be edited without an ADR.

## Exit

An ABL agent runs, calls a tool, is allowed/denied correctly, and its run replays from the log; bypass test green; 95% gates met;
independent review done. Known risk: Temporal Python test server may not be downloadable in the build sandbox; see NEEDS.
