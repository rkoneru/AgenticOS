# Eval Hub threat model

Scope: `services/eval-hub`, registry/marketplace gating hooks, gateway evals operations. Assets: integrity of the "this version passed its
evals" claim, tenant data in datasets, reviewer independence.

| Threat                                   | Mitigation                                                                                                                                                                                      | Test / residual                                                                                                                                                                                                                |
| ---------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| Score forgery by a runner                | Hub recomputes everything from per-case grades (`aggregateGrid`); any claimed aggregate mismatch rejects the result; stored runs re-verified at gate time; DB trigger freezes final runs        | runs/integrity tests, mutation "trust the runner aggregate". Residual: a malicious runner can still lie about raw per-case grades (graders run on its host); model-graded cases are only as honest as the runner (NEEDS #297)  |
| Runner impersonation                     | Gate counts only registered, non-revoked runners; run bound to runner id in provenance; HMAC `x-axis-runner-signature` over exact body; runner may only touch its own claimed run               | dev-server and gate tests. Residual: dev static tokens, no mTLS (NEEDS #294)                                                                                                                                                   |
| Dataset poisoning                        | Datasets and suites immutable and content-hashed; run bound to dataset and suite hashes; PHI redacted pre-persist; changing a dataset makes a new version and old runs no longer match          | catalog tests. Residual: a tenant admin can add easy cases to a new suite version; the gate cannot judge dataset quality (NEEDS #299)                                                                                          |
| Judge prompt injection                   | Model graders run in the runner; hub only stores scores and ids; judge output never executes; human rubric/comments printed inert; comments redacted                                            | Residual: injected agent output can sway a model judge; deterministic graders and human review mitigate (NEEDS #297)                                                                                                           |
| Baseline tampering                       | Baselines append-only (trigger); set/promote admin-only and audited; baseline run must verify or the gate blocks                                                                                | baselines tests, mutation "skip regression check"                                                                                                                                                                              |
| Replay of old passing runs               | Gate binds to content hash, suite_hash, dataset_hash; freshness (`max_age_days`); latest run decides, so a newer failing run blocks; mode must be ci/manual                                     | gate tests, mutation "skip hash binding"                                                                                                                                                                                       |
| Gate bypass via direct registry call     | `setVersionPublic` and marketplace submit/decide call the injected `EvalGatePort` (default DENY_ALL); gate errors deny                                                                          | registry/marketplace tests, mutation "port default allow". Residual: the registry only calls the gate when the ABL declares suites; tenant-required suites apply only when the gate is invoked with a declaration (NEEDS #298) |
| Cross-tenant read/write                  | Forced RLS on `eval_hub_docs`; tenant from credential only; foreign ids 404                                                                                                                     | stores/tenancy tests, mutation "cross-tenant read"                                                                                                                                                                             |
| Reviewer collusion                       | Reviewer != blueprint publisher or run starter; double grading with adjudication; all audited                                                                                                   | reviews tests, mutation "allow reviewer == publisher". Residual: publisher lookup is null for non-registry blueprints (NEEDS #300)                                                                                             |
| Attestation forgery                      | DSSE Ed25519 verified against trusted hub keys; subject must match ns/name@version and content hash                                                                                             | registry eval-gate tests. Residual: ephemeral key, no KMS (NEEDS #293)                                                                                                                                                         |
| Audit gap                                | Decision audited before it is returned; failure denies                                                                                                                                          | gate tests                                                                                                                                                                                                                     |
| Eval run reaches humans / side effects   | Eval-mode gate denies non-function actions; function tools are fixtures; the kernel returns REQUIRE_APPROVAL with `eval-dry-run` and opens no request (`eval_mode`, stripped from policy input) | `test_18`, mutants "eval mode opens a real approval request", "eval mode lets a code/MCP/browser action through". Residual: the marker is accepted from any authenticated caller; it can only remove effects (NEEDS #325)      |
| Online sampler feeds back                | Read-only token, redacted feed, results never read by the gate                                                                                                                                  | `test_15`, mutant "an online result changes release state"                                                                                                                                                                     |
| Runner reads other blueprints            | Manifest route only for a running run of that version, own tenant                                                                                                                               | `test_19`, mutant "a runner may read the manifest of a blueprint it is not executing"                                                                                                                                          |
| Caller omits suites to get a green light | Gateway adds the stored ABL's declared suites; hash must match                                                                                                                                  | gateway tests, `test_04`, mutant "gateway gate route forgets the suites"                                                                                                                                                       |
