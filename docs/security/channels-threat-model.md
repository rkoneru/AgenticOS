# Threat model: channels service

Assets: tenant isolation of conversations and identities; integrity of who-said-what in transcripts; the outbound send path; provider credentials.

| Threat                                                            | Control                                                                                                                                   | Residual                                             |
| ----------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------- | ---------------------------------------------------- |
| Forged webhook                                                    | Provider signature per route secret, constant-time compare; any failure is a reject + audit                                               | Secrets inline in config (NEEDS 504)                 |
| Replay of a genuine webhook                                       | Timestamp window + idempotency store (+ unique message key in Postgres)                                                                   | Per-instance store; SMS has no timestamp (NEEDS 505) |
| Cross-tenant routing by content                                   | Tenant read from the route after verification; adapter output re-checked against the route; claimed key only picks the secret             | A leaked route secret is that tenant's compromise    |
| Route enumeration                                                 | Unknown route and bad signature return the same 401                                                                                       | Timing differences are not measured                  |
| Single-byte tampering                                             | HMAC over raw bytes (property tests mutate every position)                                                                                |                                                      |
| JWT confusion (alg none/HS256, weak keys, wrong aud/iss, expired) | RS256 only, kid from injected JWKS, 2048-bit minimum, iss/aud/exp/nbf, serviceurl binding                                                 | JWKS rotation not built (NEEDS 503)                  |
| SSRF via attachment URLs                                          | Attachment URLs are never read, stored or fetched; metadata only (name, type, size, opaque provider id)                                   | Media service NEEDS 506                              |
| SSRF via outbound                                                 | Targets built from fixed provider hosts or route config; `GuardedHttpTransport` https + host allowlist + no IP/port/credentials/redirects | DNS rebinding of an allowlisted name not pinned      |
| Header / mention injection                                        | Email: strict addresses, control-character check, base64 body, generated headers; Slack text escaped; destinations validated per channel  |                                                      |
| Mail loops                                                        | Inbound auto-reply/bulk/list/bounce/self suppressed; outbound carries Auto-Submitted                                                      |                                                      |
| Identity takeover by claim                                        | No merge on claims; link needs a single-use code from a verified identity, same tenant, throttled                                         | Code interception on the issuing channel             |
| Thread hijack                                                     | A thread hint resumes only the same end user's conversation                                                                               |                                                      |
| Transcript leakage                                                | Audit holds hashes and sizes only; log content per policy; PHI forces redaction; failing hook stores nothing                              | Redaction is a net (NEEDS 510)                       |
| Audit flooding by forgers                                         | Rejection audits rate limited per tenant/channel                                                                                          | Events beyond the limit are logged only              |
| Outbound without the gate                                         | Reached from the runtime only via `MessageSend` (gate, audit, perform); service audits before sending, fail closed                        | Bearer token holder can bypass the gate (NEEDS 507)  |
| Unsolicited outbound spam                                         | Known-identity-only unless route opts in; per-route outbound rate limit                                                                   |                                                      |
| Cross-tenant DB access                                            | Forced RLS, `withTenant`, composite FKs; insert-only message log                                                                          |                                                      |
