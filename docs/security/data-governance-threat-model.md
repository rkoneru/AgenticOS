# Data governance threat model (STRIDE)

| Threat                                                                               | Mitigation                                                                                                 | Test                                                                                         |
| ------------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------- |
| S: a non-officer or another tenant's officer drives DSAR/holds/retention             | `requireOfficer` on every operation; tenant from the credential; lookups scoped by tenant under FORCED RLS | dsar.test.ts "requires the privacy_officer role", "invisible across tenants"; server.test.ts |
| S: attacker files a DSAR for someone else                                            | `RequesterVerifier` gate; nothing exports/erases before `verified`; failed verification audited DENY       | dsar.test.ts "failed verification"                                                           |
| T: erase wipes the wrong person/tenant                                               | exact-match identifiers; RLS tenant scope; sole-owner refusal; tenant isolation property                   | dsar.property.test.ts, pg.test.ts, mutation.py                                               |
| T: tampered export bundle                                                            | Ed25519 signature over the manifest, per-collection hashes                                                 | dsar.test.ts export tamper cases                                                             |
| R: erasure without evidence / evidence containing PII                                | audited start/complete; proof hash; `assertNoRawPii`; chain verified after erase                           | pg.test.ts, dsar.test.ts                                                                     |
| I: PII in audit, logs, errors                                                        | keyed pseudonyms, sealed identifiers, canary scan of tables/logs/errors                                    | phi-canary.test.ts                                                                           |
| I: cross-region disclosure (export, model call, writes)                              | fail-closed ResidencyPolicy, gateway region check                                                          | residency*.test.ts, test_model_residency.py                                                  |
| D: erase half-done after a crash                                                     | idempotent providers, sealed identifiers, verification pass always re-runs                                 | dsar.property.test.ts (crash at every checkpoint)                                            |
| D: holds bypassed by purge                                                           | class-wide skip + protection list; property test                                                           | retention.test.ts, mutation.py                                                               |
| E: governance role abused to rewrite history                                         | role limited to named columns by trigger; no audit grants; `current_user` check                            | pg.test.ts "governance role itself cannot"                                                   |
| E: purge below legal minimum                                                         | floors in `effectiveRetention`; audit never purged                                                         | retention.test.ts                                                                            |
| Residual risks: NEEDS 362-379 (no KMS, backups, free-text discovery, verifier stub). |
