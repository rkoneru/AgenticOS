# Threat model: Risk Kernel (STRIDE)

Scope: `services/risk-kernel`, the gate in front of every tool, MCP, model, memory, message, code and browser action.
Assets: correctness of allow/deny, tenant isolation of decisions, audit completeness, availability of the kill-switch.

| STRIDE            | Threat                                                                      | Mitigation (evidence)                                                                                                                | Residual / open                                                                                     |
| ----------------- | --------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------ | --------------------------------------------------------------------------------------------------- |
| Spoofing          | Caller claims another tenant                                                | Tenant derived from credential; mismatch -> DENY (`grpc.test.ts`)                                                                    | Static tokens are dev-only; mTLS/JWT in Phase 6                                                     |
| Spoofing          | Request context injects `tenant`/`agent`/`actor` to satisfy a rule          | Kernel overwrites those fields after spreading context (`kernel.test.ts` spoof test; mutation-checked)                               | -                                                                                                   |
| Tampering         | Malformed/hostile policy output widens access                               | Strict result validation; unknown decision, missing approval/redaction -> DENY (16 fail-closed cases)                                | Bundle integrity/signing not built                                                                  |
| Tampering         | Type confusion in rules (`"99999" > 1000`)                                  | Every leaf is a total boolean; numeric ops require `is_number`; missing field = false (`compile.test.ts`, evaluated by real OPA)     | -                                                                                                   |
| Tampering         | Caps raced by parallel requests                                             | Atomic `reserve` + rollback; 10 parallel requests against a cap of 100 allow one (`kernel.test.ts`, mutation-checked)                | Redis implementation must keep the reserve atomic                                                   |
| Tampering         | Missing/mistyped data skips a DENY rule                                     | Three-valued semantics: DENY rules match on possibly-true; differential test vs real OPA + monotonicity property (`compile.test.ts`) | `exists` is definite by design                                                                      |
| Tampering         | Regex meaning differs between JS validation and OPA (RE2)                   | Compiler accepts only RE2/JS-common syntax, rejects lookaround, backrefs, flags, named groups                                        | -                                                                                                   |
| Tampering         | Hostile context (NaN, cycles, 5000-level nesting, huge) to crash/skip audit | Iterative shape validation; rejected and audited in the authenticated tenant's chain                                                 | -                                                                                                   |
| Tampering         | Tool kill-switch sidestepped by omitting `tool.name`                        | Tool scope is checked against both the action and the declared tool name                                                             | -                                                                                                   |
| Tampering         | Counter key collisions via `:` in names                                     | JSON-encoded key parts                                                                                                               | Agent name / run id are runtime-supplied (trusted); no tenant-wide budget scope yet                 |
| Repudiation       | Decision without a record                                                   | Audit append precedes the response; failed append -> DENY                                                                            | Invalid requests are not chained (no trustworthy tenant); owner/superuser trust boundary (ADR-0008) |
| Info disclosure   | PHI/values leak via reasons or audit                                        | Audit stores hashes only; reasons name fields/limits, never values (`kernel.test.ts`)                                                | Logger fields must stay value-free (review item)                                                    |
| Denial of service | Slow/hanging policy or store stalls agents                                  | Time budget -> DENY; store errors -> DENY                                                                                            | Wasm eval can't be pre-empted (worker isolation is a hardening item); rate limits are per-gate      |
| Denial of service | Attacker triggers kill-switch                                               | Tenant credentials can only switch their own tenant; global needs platform operator                                                  | Operator credential handling is Phase 6                                                             |
| Elevation         | Agent bypasses the gate by calling tools/models directly                    | Runtime has a single `ActionExecutor`; bypass tests (Python AST + per-action-type DENY tests; TS failure-mode tests)                 | Only as strong as the allowlist review of modules that may do IO                                    |
| Elevation         | Prompt injection persuades the agent to attempt a dangerous action          | Gate is deterministic and outside the model; default-deny; approvals for risky actions                                               | Red-team eval suite is Phase 9                                                                      |
| Elevation         | Release of a kill-switch hidden by audit outage                             | Release requires the audit record first; engage does not (`grpc.test.ts`)                                                            | -                                                                                                   |
