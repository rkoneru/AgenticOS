# Threat model: API gateway, run service, AGIL

Scope: `apps/api-gateway`, `runtime/src/axis_runtime/runserver.py`, `services/agil`. Assets: tenant isolation, audit integrity, kill-switch
availability, credentials. Status of mitigations is as tested; open items are NEEDS #215-#234.

| #   | Threat                                         | Mitigation (test)                                                                                                                                                                   | Residual                                                                                                                   |
| --- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------- |
| 1   | Tenant spoofing (header, body, query, cursor)  | Tenant only from the credential; `X-Tenant*` 400, `tenant_id` body 422, unknown query 422, cursors HMAC-bound to tenant+resource (`security.test.ts`, mutants killed)               | none known                                                                                                                 |
| 2   | IDOR on run/approval/blueprint/audit ids       | Every port is tenant-scoped; foreign ids answer exactly like missing ones (compared byte for byte); the gateway also refuses a run service answer for another tenant (`IDOR` tests) | store bugs behind a port                                                                                                   |
| 3   | Privilege escalation across roles/keys         | OPA pack per `api.*` action, key scopes, role ceilings; approver role is the member's own (mutant killed); fail-closed on any authz error                                           | pack authoring errors (NEEDS #208)                                                                                         |
| 4   | Replay / double execution                      | Idempotency keys scoped tenant+member, fingerprinted, 24 h; in-flight 409; concurrent test                                                                                          | in-memory store (#220)                                                                                                     |
| 5   | Brute force / lookup amplification             | Failed-auth bucket per remote address checked before lookup; uniform 401; constant-time key compare in the control plane                                                            | no trusted-proxy handling (#221)                                                                                           |
| 6   | Resource exhaustion                            | Body 1 MiB, request 30 s, header limits, per-tenant buckets with costs, SSE caps and backpressure, `opa` concurrency cap, verify range cap, active-run cap in the run service       | single-instance limits                                                                                                     |
| 7   | Stolen/revoked credential on a long stream     | SSE re-checks the credential every 30 s and ends the stream                                                                                                                         | up to one interval (#227)                                                                                                  |
| 8   | Cross-origin abuse from a browser              | Exact-origin allow-list, no wildcard, no credentials mode, no cookies accepted (no CSRF surface), preflight never reflects an unlisted origin                                       | console CSP is Phase 7 D                                                                                                   |
| 9   | Unaudited or silently failed mutations         | Mutation audited BEFORE it runs; audit failure refuses the mutation; denials audited; request trace id = run trace id                                                               | denied reads are audited too, per (tenant, member, operation) burst 5 then one row per 10 s; granted reads are not audited |
| 10  | Information leak in errors                     | problem+json without exception text; response validation prevents extra fields from leaking; run service `tenant_id` echo stripped                                                  | PHI in run event `data` (#229)                                                                                             |
| 11  | AGIL influencing a decision                    | Read-only reader only; import/dependency lint; no model call by default; narrator input is an enumerated projection                                                                 | none                                                                                                                       |
| 12  | Kill-switch lies (listing says off, kernel on) | Kernel is applied first; nothing recorded on failure; engage never blocked by the record store                                                                                      | records are not the authority (#217)                                                                                       |
| 13  | Malicious policy in `policies:test`/publish    | Same size limits as a publish, async bounded `opa`, fail-closed on any evaluation failure                                                                                           | `opa` CPU cost (NEEDS #209)                                                                                                |
| 14  | Request smuggling to the run service           | Chunked bodies refused (501), Content-Length only, `Connection: close`, header caps, bearer per tenant, no tenant in the body                                                       | dev HTTP, no TLS (#230)                                                                                                    |
