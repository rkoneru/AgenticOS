# Control plane threat model (Phase 6 / A)

Scope: `services/control-plane`. Assets: tenant isolation, admin privileges, credentials (sessions, API keys, SCIM tokens, BYO model keys), the audit chain.
Trust: the HTTP caller is untrusted; the IdP is trusted for identity assertions of the organization it serves; Postgres under FORCED RLS is a second line of defence.

| #   | Threat                                                                          | Mitigation                                                                                                                                                | Evidence (test)                                                                                                                               | Residual                                                                                                                      |
| --- | ------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------- |
| 1   | Cross-tenant access by id (IDOR)                                                | tenant only from the credential; every store call takes it; FORCED RLS; foreign ids are 404; bodies naming a tenant are refused                           | `admin.test`, `properties.test` (every id op x every role leaves the other tenant unchanged), `http.test`, mutants "getMember ignores tenant" | none known                                                                                                                    |
| 2   | Privilege escalation (grant above own role, modify a higher member, last owner) | rank ceiling in code and policy; owners untouchable by lower ranks; last-owner guard in service and both stores (advisory lock)                           | `admin.test`, property "role escalation impossible", concurrent-removal test                                                                  | owner can appoint owners by design                                                                                            |
| 3   | Authorization bypass by failure                                                 | fail-closed `Authorizer`: no policy, error, timeout, malformed, non-ALLOW => DENY; omitted attribute => DENY (three-valued rules)                         | `authz.test`, 73 golden cases, mutants                                                                                                        | Wasm evaluation cannot be pre-empted (time budget is after the fact)                                                          |
| 4   | Unaudited admin change                                                          | decision is appended to the tenant chain before the mutation; append failure => 503 and no change                                                         | `admin.test` (broken sink)                                                                                                                    | audit and mutation are not one transaction (a crash between them leaves a decision without a result event)                    |
| 5   | Session theft / replay                                                          | short access token, server-side session row, rotating refresh with reuse => revoke, HttpOnly Secure SameSite=Strict `__Host-` cookies, CSRF double submit | `sessions.test`, `http.test`                                                                                                                  | no device binding; no IP/UA anomaly detection (NEEDS #714)                                                                    |
| 6   | Login CSRF / code injection / open redirect                                     | sealed one-shot login cookie, state compare, PKCE S256, nonce, org match, exact redirect URI, safe return URL                                             | `sso.test` incl. forged cookies                                                                                                               | spent-state set is per process (NEEDS #708)                                                                                   |
| 7   | JIT abuse / domain takeover                                                     | JIT only for verified e-mails at tenant-verified domains, configured non-owner role, domain exclusive to one tenant                                       | `sso.test`                                                                                                                                    | DNS verification is a stub (NEEDS #705); no check that the IdP org owns the domain                                            |
| 8   | SCIM abuse (mass role grant, deprovision bypass)                                | per-directory token (hash only), directory-scoped users, tenant-configured group->role map capped below owner, deprovision revokes sessions+keys at once  | `scim.test`, property "deprovision revokes"                                                                                                   | an IdP admin can still make every non-owner an admin through group mapping the tenant configured; owners are not SCIM-managed |
| 9   | API key theft / guessing                                                        | 256-bit keys, HMAC-only storage with pepper, constant-time compare, expiry, scopes AND role, session-only actions, one answer for every failure           | `apikeys.test`, mutants                                                                                                                       | pepper in an env secret (NEEDS #704)                                                                                          |
| 10  | BYO key disclosure                                                              | per-tenant data key under a KMS (tenant-bound context), AAD binds tenant/provider/label, no read-back API, no logging                                     | `modelkeys.test`                                                                                                                              | local KMS fake; the dev runtime endpoint carries plaintext (NEEDS #707)                                                       |
| 11  | Policy tampering                                                                | versions immutable, compile + opa check + Wasm build before publish, set re-validated before activation, baseline-deny irremovable                        | `policies.test`                                                                                                                               | a tenant can still publish a permissive pack for ITS agents (the kernel's ABAC, not this service, limits it)                  |
| 12  | Tenant tier confusion                                                           | router fails closed; never answers a dedicated tenant with the shared pool                                                                                | `tenancy.test` (two real databases)                                                                                                           | placement changes are not migrations (NEEDS #709)                                                                             |
| 13  | Region violation                                                                | writes refused for tenants homed elsewhere                                                                                                                | `admin.test`, `tenancy.test`                                                                                                                  | single-region deployment only (NEEDS #713)                                                                                    |
| 14  | Information leak in errors                                                      | opaque 500, no echo of secrets, RFC 9457 bodies without internals                                                                                         | `http.test`                                                                                                                                   | none known                                                                                                                    |
| 15  | Abuse of unauthenticated endpoints (SSO start, callback, SCIM auth failures)    | cheap rejections, body size cap                                                                                                                           | `http.test`                                                                                                                                   | no rate limiting (NEEDS #715)                                                                                                 |
