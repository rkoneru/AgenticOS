# Runbook: channels service

Dev start (not production): `AXIS_CHANNELS_TOKENS='{"<token>":{"tenantId":"<uuid>"}}' AXIS_CHANNELS_ROUTES='[...RouteConfig]' [AXIS_CHANNELS_DATABASE_URL=… AXIS_CHANNELS_ROLE=axis_app] node services/channels/dist/main.js` (prints `listening <port>`). Without a database URL the in-memory store and audit log are used.

| Symptom                             | Check                                                                                                                                                                                                                                                                                                                                                            |
| ----------------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| Provider webhooks all 401           | Secret in the route differs from the provider's; Slack/email clock skew over 5 min; Twilio `public_url` not exactly the URL Twilio calls (scheme, host, path, query); WhatsApp `app_secret` vs `verify_token` mixed up. Look for `channel.inbound.rejected` events (`code=`) in the tenant's chain; unknown routes are only in logs unless `systemAudit` is set. |
| Messages accepted but no agent turn | The inbox is only drained by a `ChannelAgentRunner` of the SAME tenant (token); check it is running (`serve()`), that its manifests include the route's agent name (`runner.skipped`), and the inbox size (full inbox: `inbound handler failed` in the log). The message is in `conversation_messages`. Phase 5 e2e: docs/runbooks/channels-voice-e2e.md.        |
| Inbound 503                         | Audit append failing (fail closed): nothing was stored; the provider will retry. Fix the audit store.                                                                                                                                                                                                                                                            |
| Inbound 429                         | Per-sender limit (30/min default).                                                                                                                                                                                                                                                                                                                               |
| Send 403 FORBIDDEN                  | Destination is not a known identity of the tenant, or not the conversation's end user; set `allow_unsolicited` on the route only deliberately.                                                                                                                                                                                                                   |
| Send 502 TRANSPORT                  | Provider refusal (Slack `ok:false`), egress guard (host not allowlisted), or timeout; a `channel.outbound.failed` event exists. Retry with the same `idempotency_key`.                                                                                                                                                                                           |
| Duplicate deliveries                | Idempotency store is per instance (NEEDS 124).                                                                                                                                                                                                                                                                                                                   |
| Link code does not work             | Expired (10 min), already used, wrong tenant, or throttled (5 attempts/min per identity).                                                                                                                                                                                                                                                                        |

Secret rotation: add the new secret as a new route is NOT possible (duplicate provider key); today rotation is a config change and restart (NEEDS 123).
